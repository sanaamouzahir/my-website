Drop poster PDFs or images in this folder.

Suggested workflow:
  1. Export each poster as PDF (or PNG)
  2. Name them something descriptive, e.g.
       closure-modeling-poster.pdf
       do-scheme-poster.pdf
  3. Update the link in PersonalLanding.jsx (search for `/posters/`).

If you have one poster, point href to that file directly:
  href="/posters/closure-modeling-poster.pdf"

If you have multiple, you can either:
  (a) Make this README a simple index.html that links them all, or
  (b) Tell Claude and they'll wire up a small modal listing them.

PDFs and images open in the browser when clicked.
